# DreamNest Web

Static legal and verification site for DreamNest.

## Included
- `index.html`: English privacy policy
- `privacy-policy.zh-Hans.html`: Simplified Chinese privacy policy
- `privacy-policy.zh-Hant.html`: Traditional Chinese privacy policy
- `privacy-policy.ja.html`: Japanese privacy policy
- `privacy-policy.ko.html`: Korean privacy policy
- `app-ads.txt`: AdMob app-ads declaration
- `styles.css`: Shared styles
- `vercel.json`: Static hosting config

## Deploy on Vercel
1. Create a new GitHub repository.
2. Push this folder.
3. Import the repository into Vercel.
4. Bind your custom domain, such as `mrbun.cn`.
5. Ensure `https://mrbun.cn/app-ads.txt` is publicly accessible.
6. Update App Store Connect privacy/support/marketing URLs to this domain.
